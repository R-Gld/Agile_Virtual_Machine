Le projet se découpe en plusieurs modules Maven interconnectés, chacun ayant des responsabilités bien définies. L'architecture modulaire facilite la maintenabilité et permet un développement parallèle.

\subsection{Module LexerParser}

Contient les grammaires Minijaja et Jajacode. Ce module est le module central du projet, c'est ici que nous visitons notre arbre généré par ANTLR et que nous produisons :

\begin{itemize}
    \item L'interprétation Minijaja
    \item La compilation Minijaja en Jajacode
    \item L'interprétation Jajacode
\end{itemize}

C'est au sein de ce module où l'on réalise aussi la gestion des erreurs et le type checking.
Concernant la gestion des erreurs, ce module implémente une stratégie de collecte centralisée (via un \texttt{DiagnosticCollector}). Plutôt que d'arrêter la compilation à la première faute, le système tente de récupérer le contexte pour rapporter un maximum d'erreurs syntaxiques et sémantiques à l'utilisateur en une seule passe.

\subsection{Module Mémoire}

Ce module, comme son nom l'indique, gère les états mémoires des programmes :

\begin{itemize}
    \item \textbf{La pile (Stack)} : gère les contextes d'exécution (Scopes) et les variables
    \item \textbf{Le tas (Heap)} : gère l'allocation dynamique des tableaux
    \item \textbf{La table des symboles} : assure le lien entre les identifiants et leurs adresses ou valeurs
\end{itemize}

\subsection{Module Compiler}

Ce module orchestre la compilation complète du code MiniJaja vers JajaCode. Il utilise les services du module LexerParser pour l'analyse et la génération de code.

\subsection{Module GUI}

L'interface graphique, réalisée en JavaFX, joue le rôle de contrôleur. Elle orchestre les appels aux différents modules.

C'est ici que l'on peut donc coder en Minijaja et l'exploiter.

Au-delà de son rôle d'orchestrateur technique, cette interface constitue le point de validation du projet en permettant de répondre point par point aux contraintes fonctionnelles imposées par le sujet.

\subsection{Structures de communication}

Les modules communiquent principalement via :

\begin{itemize}
    \item \textbf{Interfaces Java} : définition de contrats clairs entre modules
    \item \textbf{Objets de transfert} : AST, DiagnosticCollector, Stacks, SymbolTable
    \item \textbf{Événements} : notifications de changements d'état pour l'interface graphique
    \item \textbf{Maven dependencies} : gestion des dépendances inter-modules
\end{itemize}
